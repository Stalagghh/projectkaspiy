# Скиллы (справочные наборы инструкций)

Скиллы — это сторонние файлы с рекомендациями и скриптами. Для нас это справочный материал, а не источник правил: если скилл противоречит сообщениям команды, [CLAUDE.md](../CLAUDE.md) или [PLAN.md](PLAN.md), действуют наши правила.

## Что установлено

Команда 12.11.2026 установила набор в каталог `.opencode/skills/` (в git не хранится, каталог добавлен в `.gitignore`). В наборе семь скиллов, 172 файла, 4,3 МБ.

| Скилл | Что делает | Используем? |
|---|---|---|
| `ui-ux-pro-max` | Локальная база UI/UX-рекомендаций с поиском: 119 правил UX и доступности, палитры, шрифты, типы графиков, правила для 22 стеков (в том числе Next.js и React). Поиск — скриптом `scripts/search.py` на стандартной библиотеке Python | **Да** — для проверки интерфейса на этапе C: доступность, контраст, ширина телефона, состояния данных |
| `ui-styling` | Справка по Tailwind и shadcn/ui | Только как справка по Tailwind |
| `design-system` | Токены дизайна, генерация слайдов | Нет |
| `design` | Логотипы, иконки и фирменный стиль через внешний API генерации изображений | **Нет, скрипты не запускаем** (см. ниже) |
| `brand`, `banner-design`, `slides` | Бренд, баннеры, HTML-презентации | Нет — вне задач кода |

## Что проверено перед использованием

| Проверка | Результат |
|---|---|
| Скрытые символы Unicode (теги U+E0000–U+E007F, символы нулевой ширины, управление направлением текста) во всех 172 файлах | не найдено |
| Скрипты `ui-ux-pro-max` (`search.py`, `core.py`, `design_system.py`, `reasoning_contract.py`): сеть, запуск процессов, чтение ключей и переменных окружения | только стандартная библиотека; читают CSV из каталога скилла; из окружения читают одну переменную `COLORTERM`; сеть и запуск процессов не используются |
| Запись файлов | только в режиме `--persist` (создаёт каталог `design-system/`); этот режим не используем |

| Скрипты `design/scripts/{logo,icon,cip}/generate.py` | читают файлы `.env` и ключ `GEMINI_API_KEY`, отправляют запросы во внешний API — **не запускаем** |

Проверка сделана по состоянию каталога на 12.11.2026 22:50 МСК. Набор установлен сторонним установщиком, поэтому зафиксировать исходный коммит нельзя; при обновлении набора проверку нужно повторить.

## Новые скиллы

Дополнительные скиллы на спринт **не устанавливались**: до финала каждая минута уходит на демо, а `ui-ux-pro-max` уже закрывает проверку интерфейса и доступности.

Правила на будущее:

1. Источники без отдельного согласования — только официальные организации инструментов, которые мы уже используем (список согласован с командой, например `vercel-labs`, `vercel`, `microsoft`). Остальное — после согласования с командой.
2. Не запускать сторонние установщики. Клонировать репозиторий (`git clone --depth 1`) во временный каталог вне проекта и записать SHA коммита.
3. Прочитать каждый файл. Отклонить скилл, если он выполняет команды или сетевые запросы сверх заявленного назначения, читает ключи, токены, переменные окружения или файлы вне проекта, куда-либо отправляет данные, меняет `CLAUDE.md`, `AGENTS.md`, настройки или хуки, содержит исполняемые файлы, обфусцированный код или скрытые символы Unicode.
4. Устанавливать только в проект: копией проверенного каталога в `.claude/skills/<имя>/`, отдельным PR с меткой `track:P`. В этой таблице указать репозиторий, SHA коммита, sha256 каждого файла, зачем скилл нужен и что проверено.
