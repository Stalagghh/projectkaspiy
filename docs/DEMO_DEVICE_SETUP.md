# Подготовка демо-телефона и точки доступа

Для трека D (и P для команд с `sudo`). Делается один раз до демо, примерно 15 минут. Проверяем вместе с агентом до Milestone B.

Схема простая: ноутбук сам раздаёт Wi-Fi, телефон подключается к нему и открывает дашборд по HTTPS. Сертификат сайта выпускает наш локальный удостоверяющий центр (CA), поэтому телефону нужно один раз «доверить» этот CA. Wi-Fi площадки не нужен.

> **Статус.** Шаги 1 и 4 работают уже сейчас. Шаги 2–3 (HTTPS через Caddy и файл `ca.crt`) появятся в Milestone B: агент сообщит в отчёте, когда можно начинать.

## 1. Точка доступа на ноутбуке (трек P, нужен `sudo`)

Каталог: любой.

```bash
# Создать точку доступа (один раз). Пароль придумайте сами, не короче 12 символов.
nmcli dev wifi hotspot ifname wlp0s20f3 ssid EcoShield-Demo password 'ПРИДУМАЙТЕ-ПАРОЛЬ'
# Адрес ноутбука в этой сети (обычно 10.42.0.1):
nmcli -g IP4.ADDRESS dev show wlp0s20f3
# Разрешить телефону и устройствам подключаться к дашборду и MQTT через межсетевой экран Fedora:
sudo firewall-cmd --zone=nm-shared --add-port=80/tcp --add-port=443/tcp --add-port=8883/tcp --permanent
sudo firewall-cmd --reload
```

Что должно получиться:
- вторая команда показывает `10.42.0.1/24`;
- `sudo firewall-cmd --zone=nm-shared --list-ports` выводит `80/tcp 443/tcp 8883/tcp`.

Учтите: пока ноутбук раздаёт Wi-Fi, сам он через Wi-Fi в интернет не ходит. Если интернет нужен, подключите его по кабелю или через USB-модем телефона.

## 2. Корневой сертификат на телефон

Агент сгенерирует `infra/certs/ca.crt` и покажет его отпечаток SHA-256 в отчёте. Это публичная часть — её можно передавать. Закрытый ключ никогда не покидает ноутбук.

Получить файл на телефоне: подключитесь к `EcoShield-Demo` и откройте в браузере `http://10.42.0.1/ca.crt`. Отпечаток в настройках телефона должен совпасть с отпечатком из отчёта.

### iPhone (iOS 17–19)

1. Откройте ссылку в **Safari** (не в Chrome) → «Разрешить» загрузку профиля.
2. Настройки → Основные → **VPN и управление устройством** → «EcoShield Demo Local CA» → **Установить** (введите код телефона).
3. Настройки → Основные → Об этом устройстве → **Доверие сертификатам** → включите полное доверие для «EcoShield Demo Local CA».

Без шага 3 Safari будет показывать предупреждение.

### Android (13–15)

1. Скачайте `ca.crt` по ссылке в **Chrome**.
2. Настройки → Безопасность и конфиденциальность → Другие настройки безопасности → Шифрование и учётные данные → **Установка сертификата** → **Сертификат ЦС** → «Всё равно установить» → выберите `ca.crt`.
   - Названия пунктов зависят от производителя. Если не находите, наберите в поиске настроек «сертификат ЦС».
3. Для демо используйте **Chrome**: он доверяет установленным вами центрам сертификации, Firefox — нет.

## 3. Проверка на телефоне

1. Подключитесь к Wi-Fi `EcoShield-Demo`.
2. Откройте `https://10.42.0.1`.

Ожидаемое:
- страница открывается без предупреждений;
- вверху горит зелёный индикатор связи;
- после нажатия «Запустить сценарий» на ноутбуке тревога приходит и на телефон.

Агент проверит со своей стороны: телефон виден в журнале Caddy, а его SSE-подключение — в журнале веб-сервиса.

## 4. Если что-то не так

| Симптом | Причина | Что сделать |
|---|---|---|
| Телефон не видит сеть `EcoShield-Demo` | адаптер не в режиме точки доступа | повторить шаг 1; `nmcli dev status` должен показать `wlp0s20f3 … connected (EcoShield-Demo)` |
| Страница не открывается | межсетевой экран | проверить `sudo firewall-cmd --zone=nm-shared --list-ports` |
| Предупреждение о сертификате | CA не установлен или нет полного доверия (iOS) | повторить раздел 2, на iOS — пункт 3 |
| Работает, но не обновляется | телефон заснул и разорвал соединение | обновить страницу: лента перезагрузится сама |

## 5. После демо

Удалите профиль: на iOS — «VPN и управление устройством», на Android — «Шифрование и учётные данные» → «Учётные данные пользователя». Выключите точку доступа: `nmcli connection down Hotspot`.
