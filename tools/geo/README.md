# Seed-геоданные для демо «Эко-щит Каспия» (tools/geo)

Скрипт `make_seed.py` строит GeoJSON-файлы в `packages/db/seed/` (WGS84, lon/lat,
6 знаков после запятой) из данных OpenStreetMap. Все геометрии проверяются
(`shapely.is_valid`) перед записью и после повторного чтения файла.

## Как перегенерировать

```bash
cd tools/geo && uv run python make_seed.py
```

Python 3.13 (`.python-version`), зависимости зафиксированы в `pyproject.toml` и `uv.lock`
(shapely 2.1.2, pyproj 3.7.2). Ответы OSM кешируются в `tools/geo/.cache/` (в git не попадает);
чтобы скачать свежие данные, удалите этот каталог. Отдельные объекты берутся из OSM API
(`/api/0.6/<type>/<id>/full.json`), береговая линия из Overpass (скрипт перебирает несколько
серверов). Скрипт печатает сводку (площадь моря, число ячеек, координаты устройств, проверки)
и падает, если хотя бы одна проверка не прошла. Текущие файлы построены по снимку OSM от 2026-11-12.

## Файлы

| Файл | Объекты | Что это и как получено |
|---|---|---|
| `agrakhan-boundary.geojson` | 1 MultiPolygon | Граница Аграханского заказника: OSM way/505346049 (boundary=protected_area, protect_class=4). |
| `ops-area.geojson` | 1 MultiPolygon | Морская часть прямоугольника lon 47.35–48.05, lat 43.45–44.20 (иллюстративно). Линии `natural=coastline` (Overpass, бокс 43.3,47.2,44.4,48.2) вместе с контуром прямоугольника разбиваются на грани (`polygonize`); морем считаются грани, содержащие точки открытого моря (47.95, 44.05) и (47.95, 43.60), все остальные грани (материк с полуостровом, острова) вычитаются. Площадь ≈ 3547 км². Северная часть Аграханского залива в OSM лежит за береговой линией, то есть считается морем, поэтому тоже входит в зону. |
| `haulouts.geojson` | 2 Point | Кандидаты на лежбища тюленя: о. Чечень (way/5227556) и о. Яичный (relation/14553380). Точка внутри полигона острова: центроид, если он внутри, иначе point-on-surface. |
| `zones.geojson` | 2 Polygon | Демо-зоны (иллюстративно): `no_entry` — море в пределах 5 км от о. Чечень; `buffer` — кольцо 5–9 км. Остров = полигон way/5227556 плюс кольцо береговой линии вокруг него. Обе зоны обрезаны по морскому полигону; если получается несколько частей, берётся самая большая. |
| `devices.geojson` | 6 Point | Симулированные устройства (иллюстративно). buoy-01 и buoy-02 — в зоне `no_entry` к северо-востоку и юго-западу от острова (что buoy-02 внутри зоны, проверяет скрипт); buoy-03 — севернее, вне обеих зон; wq-01/02/03 — в 0.5–1.5 км от берега со стороны открытого моря на широтах 43.75 (восточный берег полуострова), 43.90 (у северной оконечности полуострова) и 43.52 (южнее). |
| `forecast-cells.geojson` | 604 Polygon | Гексагоны с ребром 1.5 км, построены в UTM 38N (EPSG:32638); гексагон остаётся, если его центр в море. `dist_haulout_km` — расстояние от центра до ближайшей точки лежбища, `dist_coast_km` — до ближайшей линии `natural=coastline` (включая берега островов); оба в км по UTM, 2 знака. |
